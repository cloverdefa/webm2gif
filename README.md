# webm2gif

Support webm and webp files to gif.

## Download

[Download webm2gif.exe](https://github.com/cloverdefa/webm2gif/releases/latest/download/webm2gif.exe)

## Usage

Run `webm2gif.exe` directly, select your folder, then click **Start**.

Just enjoy it.
